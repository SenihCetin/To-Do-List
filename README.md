# To-Do List App 📝

A modern, user-friendly To-Do List application built with Flutter. This project features a clean UI with a striking yellow and dark anthracite color palette, designed for the best user experience.

## ✨ Features
* **Add Tasks:** Quickly add new daily tasks with a custom designed dialog box.
* **Track Progress:** Mark tasks as completed with interactive checkboxes (includes strikethrough text animation).
* **Swipe to Delete:** Easily remove tasks by swiping left to reveal the delete button.
* **Modern UI:** Custom rounded corners, responsive buttons, and a cohesive color scheme.
